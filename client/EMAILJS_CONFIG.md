# EmailJS Configuration

## ✅ EmailJS is now installed!

Your contact form is ready to send emails **without a backend server**.

---

## 🔧 What You Need to Do:

### 1. Create EmailJS Account
- Go to: https://www.emailjs.com/
- Sign up (free)

### 2. Get These 3 Values:
1. **Service ID** (from Email Services)
2. **Template ID** (from Email Templates)  
3. **Public Key** (from Account settings)

### 3. Update Contact.jsx
Open: `src/components/Contact/Contact.jsx`

Find line ~50 and replace:
```javascript
const serviceId = 'YOUR_SERVICE_ID';
const templateId = 'YOUR_TEMPLATE_ID';
const publicKey = 'YOUR_PUBLIC_KEY';
```
