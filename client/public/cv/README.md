# CV/Resume Directory

## Instructions

Place your resume PDF file in this directory with the name `pro.pdf`

### Steps:

1. **Prepare your resume PDF**
   - Make sure it's a valid PDF file
   - Recommended size: Under 5 MB
   - File should be named: `pro.pdf`

2. **Add the file**
   - Copy your resume PDF to this directory: `portfolio/client/public/cv/`
   - Rename it to: `pro.pdf`

3. **Verify it works**
   - Start the dev server: `npm run dev`
   - Visit: `http://localhost:3000/cv/pro.pdf`
   - You should see your resume in the browser
   - Test the download buttons on your portfolio site
