# CV/Resume Folder

Place your CV/Resume PDF file here with the name: `Ashenafi_CV.pdf`

The download button in the Resume section will link to this file.

## Instructions:
1. Create or export your CV as a PDF file
2. Name it `Ashenafi_CV.pdf`
3. Place it in this folder (`client/public/cv/`)
4. The download button will automatically work

## Alternative:
If you want to use a different filename, update the link in:
`client/src/components/Resume/Resume.jsx`

Change the href from `/cv/Ashenafi_CV.pdf` to your preferred filename.
